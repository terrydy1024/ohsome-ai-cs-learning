# 会员产品经理训练工作台 V5.0

## 文件说明

- `会员产品经理训练工作台_V5.0_模拟建议完整版.html`：主学习工作台，双击即可打开。
- `V5_模拟建议方案.md`：本版本对原方案缺口给出的完整模拟产品建议。
- `25年新BO会员体系+徽章设计方案 技术版.md`：用户提供的原始业务方案。
- `QA_完整检查报告.md`：本次内容、结构、交互和视觉检查结果。

## 建议学习顺序

1. 先进入“模拟建议方案”，理解本版本对价格、退款、续费和迁移的明确设计。
2. 按 01—13 顺序完成案例实验室。
3. 每个实验室先做判断，再查看专家分析。
4. 运行模拟器，完成独立输出和两分钟口述。
5. 在 D+1、D+3、D+7、D+14 进入复习中心重新提取知识。
6. 需要查字段、状态和完整知识时，再进入“系统知识课”和“完整知识手册”。

## 数据保存

学习进度、笔记、错题和复习计划默认保存在浏览器本地。若当前浏览器限制本地存储，工作台会自动使用当前页面的内存存储；这种情况下关闭页面后数据不会保留。

## 内容边界

工作台明确区分：

- 原方案事实：来自上传的 BO 会员方案；
- 推荐方案：为模拟学习给出的产品设计；
- 训练扩展：用于理解通用会员产品能力，不代表原项目实际建设。
