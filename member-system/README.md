# 会员产品经理训练工作台 V6.0

## 打开方式

双击 `会员产品经理训练工作台_V6.0_清晰导航版.html`，使用 Chrome、Edge 等现代浏览器打开。

工作台为单文件 HTML，不依赖网络；学习进度、课程步骤、笔记、错题和复习记录保存在当前浏览器本地。

## V6.0 主要变化

1. 左侧一级导航由 37 个入口压缩为 6 个：今日学习、学习路径、课程中心、训练与复习、我的掌握度、资料库。
2. 原“案例实验室”和“系统知识课”合并，同一知识主题只保留一个入口。
3. 12 门核心课程和 1 个徽章综合案例，均采用六步学习流程：先判断、看图理解、专家推导、操作模拟、独立设计、口述与复习。
4. 每门课在同一页面切换：学习流程、知识手册、案例与练习、我的笔记。
5. 复习、错题和口述训练合并到同一训练中心。
6. 完整知识内容按章节折叠，避免长页面一次性铺开。
7. 移动端增加：首页、课程、复习、我的四项底部导航。

## 推荐使用顺序

1. 从“今日学习”进入系统推荐的下一步。
2. 在“课程中心”按四阶段学习。
3. 每门课完成判断、设计和口述三个核心动作。
4. 到“训练与复习”完成 D+1、D+3、D+7、D+14 复习。
5. 需要查规则时再进入课程内“知识手册”或全局“资料库”。
