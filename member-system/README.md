## 打开方式

直接双击：

`会员产品经理训练工作台_V4.0_完整训练版.html`

建议使用最新版 Chrome 或 Edge。文件为单HTML离线版本，不依赖网络、服务器或外部资源。

## V4.0 完整改造内容

本版将全部核心知识模块改造成案例实验室，共13个：

1. 会员战略
2. 账户与 One ID
3. 等级与成长值
4. 积分退款
5. 权益履约
6. 付费会员
7. C端体验
8. 生命周期增长
9. 指标与财务
10. 会员平台架构
11. 风控、合规与 AI
12. PRD与研发评审
13. 徽章退款回退综合题

每个实验室都包含：

- BO方案事实卡；
- 视觉结构图；
- 课前判断题；
- 专家推导；
- 可操作模拟器；
- 独立产品输出；
- 两分钟口述训练；
- D+1、D+3、D+7、D+14复习任务。

## 学习建议

建议按左侧实验室顺序学习。每次只完成一个实验室，不要连续阅读多个知识章节。

一个实验室的完成标准是：

1. 先完成课前判断；
2. 阅读专家分析并记录遗漏；
3. 操作模拟器改变条件；
4. 独立输出规则、流程或指标；
5. 不看资料完成两分钟口述；
6. 按复习中心完成间隔复习。

## 事实边界

- “方案原文事实”来自同目录的《25年新BO会员体系+徽章设计方案 技术版.md》。
- 原方案没有定义的账户合并、退款欠回、ROI、幂等、AI客服等内容，均明确标记为“训练推演”或“训练扩展”。
- 付费价格、退款政策、香港换算、实时降级等业务TBD仍需要业务、财务、法务或技术团队确认，工作台不会用通用知识替代正式决策。

## 数据保存

学习进度、错题、笔记和复习任务保存在当前浏览器的本地存储中。清理浏览器站点数据或更换浏览器后，记录可能丢失。
