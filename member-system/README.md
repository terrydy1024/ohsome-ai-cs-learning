# 会员产品经理训练工作台 V7.0

## 使用方式

直接双击打开：

`会员产品经理训练工作台_V7.0_连续学习版.html`

该文件为单文件离线HTML，不依赖外部服务器。学习进度、判断理由、独立设计、笔记和复习记录保存在当前浏览器本地。

## 本版核心变化

1. 每门课只保留三个入口：课程学习、知识索引、我的笔记。
2. 删除独立“案例与练习”入口，案例直接成为课程主线。
3. 六步流程统一为：进入案例 → 我的判断 → 核心知识 → 案例拆解 → 模拟与设计 → 口述与复习。
4. 每门课新增“本课解决的问题、需要理解、学完输出”学习契约。
5. 核心知识直接嵌入课程流程，不需要在案例、知识和练习之间反复跳转。
6. 专注模式增加固定退出入口，支持Esc退出，并同步调整课程Tab与步骤栏位置。
7. 深色模式统一使用语义颜色，修复步骤、标签、提示框和SVG图中文字可读性。
8. 移动端复杂SVG使用局部横向查看，不再把图压缩到无法阅读。

## 推荐学习方式

一门课按顺序完成六步，不建议先通读完整知识手册：

1. 先理解案例问题；
2. 提交自己的判断；
3. 学习当前案例必需的三个核心知识点；
4. 查看专家如何拆解案例；
5. 操作模拟器并完成产品输出；
6. 完成两分钟口述和间隔复习。

“知识索引”仅用于补查完整规则、字段、状态和扩展内容。
