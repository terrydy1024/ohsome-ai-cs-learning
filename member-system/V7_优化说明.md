# V7.0 优化说明

## 一、解决的问题

### 1. 专注模式无法退出

新增固定专注顶部栏，保留：

- 退出专注；
- 当前课程；
- 当前学习步骤；
- 夜间模式。

同时支持按 `Esc` 退出。

### 2. 专注后课程Tab悬浮在半空

专注模式下：

- 全局顶部栏和左侧导航隐藏；
- 课程Tab固定在专注顶部栏下方；
- 六步步骤栏固定在课程Tab下方；
- 内容自动补足顶部间距，不会被遮挡。

### 3. 学习流程与知识点脱节

原结构中，“学习流程、知识手册、案例与练习”彼此独立。V7改为单条教学路径：

`进入案例 → 我的判断 → 核心知识 → 案例拆解 → 模拟与设计 → 口述与复习`

每门课在“核心知识”步骤直接展示解决当前案例所需的三个知识点，包括：

- 一句话解释；
- 在案例中的作用；
- 常见误区。

### 4. 案例与学习流程重复跳转

删除独立“案例与练习”Tab。案例事实、判断题、专家分析、模拟器和独立练习全部放入同一连续课程流程。

### 5. 夜间模式文字不可读

新增统一语义颜色变量，覆盖：

- 六步学习流程；
- 方案事实与推荐标签；
- 警告、成功、风险提示；
- 表单和知识折叠面板；
- SVG流程图文字。

### 6. 移动端复杂图过小

复杂SVG在手机端改为组件内横向查看，页面本身不产生横向溢出。

## 二、课程结构

13门课程全部统一为：

- 课程学习；
- 知识索引；
- 我的笔记。

每门课都包含：

- 业务案例；
- 课前判断；
- 三个核心知识点；
- 专家案例拆解；
- 交互模拟器；
- 独立产品设计；
- 口述和复习。
