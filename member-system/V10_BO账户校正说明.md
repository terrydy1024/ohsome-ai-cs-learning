# V10.0 BO账户校正说明

## 本次校正结论

V9原账户课程的部分内容把BO场景理解为“零售、电商、乐园存在多个会员账号，需要统一合并资产”。该理解与用户补充的真实业务不一致。

V10统一改为：

```text
BO集团会员始终只有一个会员主体
＋
乐园保留独立外购会员账号
＋
用户先在哪边注册，都可以在另一边补齐账号并建立关联
＋
乐园资产不迁移，继续由乐园系统管理
```

## 删除或纠正的旧表达

已经清除以下错误场景：

- BO存在多个集团会员入口；
- 零售、电商、乐园分别形成三个BO会员账号；
- 通过One ID把三套集团会员资产集中迁移；
- 乐园账号可被BO账号直接替代；
- 手机号命中后将乐园资产搬入BO。

## 最终业务边界

| 对象 | 权威系统 | 是否保留 | 是否迁移 |
|---|---|---:|---:|
| BO集团会员 | BO会员系统 | 是 | 不适用 |
| BO积分/等级/权益 | BO会员系统 | 是 | 不迁移到乐园 |
| 乐园账号 | 乐园外购系统 | 是 | 不迁移到BO |
| 乐园资产 | 乐园外购系统 | 是 | 不迁移到BO |
| BO—乐园关联关系 | 集成/会员关联表 | 是 | 保存两边账号映射 |
